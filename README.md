## About Me

I'm a Python backend developer and BCA student from Butwal, Nepal. I build real, working web applications — not just tutorial projects — and I care about clean code, honest features, and shipping things people can actually use.

- **Currently:** Django Developer Intern at Name It Education
- **Education:** Bachelor of Computer Applications (BCA), Butwal Kalika College, Tribhuvan University — graduating 2027
- **Working on:** [TopDownloads](https://topdownloads.me) (live) and SkillGap, my final-year project
- **Interests:** backend development, REST APIs, databases, and building tools that solve real problems
- **Currently learning:** Django REST Framework, FastAPI, and UI/UX design
- **Long-term:** full-stack development, and building my own products that earn on their own

### TopDownloads — Live

A free multi-platform video & audio downloader for YouTube, Instagram, Facebook, TikTok, Twitch, and Kick. Paste a public link, pick a format, download — no account needed. Built with Django + Django REST Framework, yt-dlp, and FFmpeg, with the frontend on Cloudflare Workers.
